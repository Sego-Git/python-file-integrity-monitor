What this project is about of?
"Has any file in this folder been modified, added, or deleted since the last time I checked?" : this is called *Python File integrity monitor(FIM)

A simplified version of how real security tools work is:

           Files on computer
                  │
                  ▼
        ┌───────────────────┐
        │ Calculate SHA-256 │
        │ hash of each file │
        └─────────┬─────────┘
                  │
                  ▼
        ┌───────────────────┐
        │ Save known hashes │
        │   baseline.json   │
        └─────────┬─────────┘
                  │
              Later...
                  │
                  ▼
        ┌───────────────────┐
        │ Calculate hashes  │
        │      again        │
        └─────────┬─────────┘
                  │
                  ▼
          Compare hashes
             /    |    \
            /     |     \
       Modified Added  Deleted

What does "baseline" mean?

In a File Integrity Monitor(FIM), a baseline is the trusted,
original state of a file that we use as a reference for future comparisons

What does JSON mean?

JSON stands for: JavaScript Object Notation. Despite the name, JSON is not only for Javascript.
Almost every modern programming language can work with JSON, including Python.

***JSON is simply a standard format for storing and exchanging structured data.

Understanding the basic JSON structured

JSON is built around key-value pairs

for example:
{
    "name": "Alice",
    "age": 25,
    "country": "Cameroon"
}

here:

"name"     → "Alice"
"age"      → 25
"country"  → "Cameroon"

The left side is the **key
The rigth side is the **value

We can think of it like a Python dictiorary

In Python:
person = {
    "name": "Alice",
    "age": 25,
    "country": "Cameroon"
}

JSON looks almost identical:
{
    "name": "Alice",
    "age": 25,
    "country": "Cameroon"
}
